## 3) สิ่งที่ต้องทำ

1. สร้าง **Theme Builder ชุดเดียว** — Header / Footer / 404  
2. บันทึก **Divi Library** ตาม T1–T6 + หน้า custom ตามตาราง  
3. สร้าง **ประมาณ 70 เพจ** ตาม `sitemap-70.md`  
4. ยึดสี `#123880` / `#FFC20E` / `#F5F7FA` ฟอนต์ **Prompt**  
5. แยก **ฐานความรู้ (โหลดไฟล์)** กับ **E-Library (ยืม–คืนภายนอก)**  
6. **หนึ่งหมวด = หนึ่งแม่พิมพ์** — ห้ามปน sidebar กับ full-width ในหมวดเดียวกัน

---

## 4) สิ่งที่ห้ามทำ

- ห้ามออกแบบสัดส่วนคอลัมน์ใหม่นอกไฟล์ใน `demo/`  
- ห้ามคิดว่า HTML เป็นไฟล์ import Divi ได้ตรงๆ  
- ห้ามสร้าง Template 70 แบบ (แค่ ~6–10 แม่พิมพ์ + สลับเนื้อหา)  
- ห้ามใส่ระบบยืม–คืนหนังสือในหน้าฐานความรู้  
- ห้ามสร้างหน้าที่ถูกตัดซ้ำ (ดูท้าย `sitemap-70.md`)

---

## 5) คำศัพท์ที่ใช้กับงานนี้

| ใช้คำนี้ | ไม่ใช้คำนี้ |
|----------|-------------|
| Theme Builder / Divi Library / Page Template | router |
| แม่พิมพ์ T1–T6 | ธีมคนละตัวต่อหน้า |
| Custom landing | ระบบคนละ CMS |

---

## 6) ประโยคสรุปส่งงาน

> เปิด HTML Demo เป็นต้นแบบภาพ  
> สร้าง Theme Builder ชุดเดียว + Divi Library ตาม T1–T6 และหน้า custom  
> หน้าในหมวดเดียวกันต้องใช้แม่พิมพ์เดียวกัน  
> ห้ามออกแบบสัดส่วนใหม่นอก `demo/`  
> สัญญา = 70 เพจ · Library ≈ 6–10 แบบ
