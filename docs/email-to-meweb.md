# ร่างอีเมลถึงบริษัท Meweb

**หัวข้ออีเมล:**  
ขอเสนอขอบเขตงานออกแบบและพัฒนาเว็บไซต์ โรงเรียนสระบุรีวิทยาคม (www.sbw.ac.th) — WordPress + Divi

---

เรียน ทีมงานบริษัท Meweb

เนื่องด้วยโรงเรียนสระบุรีวิทยาคม มีความประสงค์พัฒนาเว็บไซต์สถานศึกษาใหม่บนระบบ WordPress ด้วยธีม Divi เพื่อประชาสัมพันธ์ข้อมูลสถานศึกษา เป็นศูนย์รวมระบบสารสนเทศ (Portals) รองรับการรับสมัครนักเรียนใหม่ และเปิดเผยข้อมูลสาธารณะ (ITA)

จึงขอส่งเอกสารบรีฟตามแบบฟอร์มมาตรฐาน 7 ส่วนของทางบริษัท พร้อมไฟล์ตัวอย่างหน้าเว็บ (HTML Demo) และคู่มือส่งงาน เพื่อใช้ประกอบการประเมินราคา ขอบเขตงาน และระยะเวลาดำเนินงาน

**ลิงก์สำคัญ**

```text
1) Demo ออนไลน์ (Vercel):  https://sbw-demo-ten.vercel.app/
2) ซอร์ส GitHub:           https://github.com/saengpech-sys/sbw-demo
```

**ลำดับอ่านเอกสาร (สำคัญ)**

1. เปิด Demo ออนไลน์ไล่เมนูก่อน  
2. `docs/meweb-read-this.md` — หน้าปกสั่งงาน  
3. `docs/meweb-brief.md` — ฟอร์ม 7 ส่วน  
4. `docs/meweb-handoff-guide.md` — คู่มือละเอียด Divi  
5. `docs/sitemap-70.md` — ตารางครบ 70 เพจ

**ความต้องการหลักโดยสรุป**
- CMS: WordPress + Divi (ลิขสิทธิ์แท้)
- Theme Builder: Header / Footer / 404
- สัญญาเพจ: **ประมาณ 70 หน้า** (ไม่ใช่ 70 templates)
- Divi Library: แม่พิมพ์ 6–10 เลย์เอาต์ (T1–T6 + custom)
- Custom Landing: Homepage, Admissions, Portals, SBW-AI Center, Alumni, ITA, E-Library
- ฐานความรู้ = โหลดไฟล์ · E-Library = แนะนำหนังสือ + ลิงก์ระบบยืม–คืนภายนอก
- หนึ่งหมวด = หนึ่งแม่พิมพ์
- Global Settings: สี `#123880` / `#FFC20E` / `#F5F7FA` ฟอนต์ Prompt
- ปุ่มทางลัด / SSO เข้าสู่ระบบ Dschool AI
- อบรมและคู่มือการใช้งานสำหรับแอดมินโรงเรียน
