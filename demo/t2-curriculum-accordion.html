เข้าสู่ระบบ (Portals)

โครงสร้างหลักสูตรและวิชาการ

Curriculum & Academic Structure

หลักสูตรมัธยมศึกษาตอนต้น

แผนการเรียนวิทยาศาสตร์ - คณิตศาสตร์ (พิเศษ) +

มุ่งเน้นการปูพื้นฐานทางวิทยาศาสตร์และคณิตศาสตร์อย่างเข้มข้น เพื่อเตรียมความพร้อมสำหรับการศึกษาต่อในระดับมัธยมศึกษาตอนปลายที่เน้นสายวิชาการ

  • คณิตศาสตร์เพิ่มเติม (การแก้ปัญหาเชิงตรรกะ)
  • วิทยาศาสตร์ประยุกต์และโครงงาน
  • ภาษาอังกฤษเพื่อการสื่อสารเชิงวิชาการ
แผนการเรียนวิทยาการคำนวณและหุ่นยนต์ (Robotics & AI) +

ส่งเสริมทักษะในศตวรรษที่ 21 ผ่านการเรียนรู้ระบบอัตโนมัติ การเขียนโปรแกรมเบื้องต้น และการสร้างสรรค์นวัตกรรมผ่านโครงงานหุ่นยนต์ (เตรียมความพร้อมสู่การแข่งขัน TPA Robot ระดับประเทศ)

  • พื้นฐานการออกแบบและเทคโนโลยี
  • การประกอบและเขียนโปรแกรมควบคุมหุ่นยนต์ (Robo Rescue / Robo Soccer)
  • ตรรกศาสตร์และการแก้ปัญหาเชิงคำนวณ (Computational Thinking)

หลักสูตรมัธยมศึกษาตอนปลาย

กลุ่มวิชาเพิ่มเติม: วิทยาการคำนวณและเทคโนโลยีปัญญาประดิษฐ์ +

เตรียมความพร้อมผู้เรียนสู่สายอาชีพด้านเทคโนโลยี ด้วยสภาพแวดล้อมการเรียนรู้แบบออนไลน์ (เช่น The AI Forge) เพื่อฝึกทักษะการเขียนโปรแกรมและการเทรนโมเดล AI เบื้องต้น

รหัสวิชา ชื่อวิชา หน่วยกิต
ว30281 การพัฒนาแอปพลิเคชันด้วย Python และ Vue.js 1.5
ว30282 โครงงานปัญญาประดิษฐ์ (AI Project) 1.5
กลุ่มวิชาเพิ่มเติม: ระบบสารสนเทศเพื่อการลงทุน (สำหรับนักเรียน ม.6) +

หลักสูตร 40 ชั่วโมงที่ออกแบบมาเพื่อบูรณาการความรู้ทางคณิตศาสตร์ สถิติ และวิทยาการคอมพิวเตอร์เข้ากับความรู้ทางการเงิน (Financial Literacy)

  • การวิเคราะห์ข้อมูลทางสถิติและการทำ Backtest เบื้องต้น
  • การพัฒนาระบบเทรดอัตโนมัติ (Trading Bot) ด้วยภาษา Python
  • การเชื่อมต่อ API ของระบบสารสนเทศข้อมูลการลงทุน
  • ความเสี่ยงทางการเงินและวินัยการลงทุน
