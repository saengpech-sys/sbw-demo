เข้าสู่ระบบ (Portals)
กลุ่มวิชาเพิ่มเติม: วิทยาศาสตร์และเทคโนโลยี

ระบบสารสนเทศเพื่อการลงทุน (Investment Information Systems)

บูรณาการวิทยาการคอมพิวเตอร์และสถิติเข้ากับความรู้ทางการเงิน เพื่อพัฒนาระบบเทรดอัตโนมัติ (Python Trading Bot) ด้วยข้อมูลแบบ Real-time

คำอธิบายรายวิชา (Course Overview)

รายวิชา 40 ชั่วโมงที่ออกแบบมาสำหรับนักเรียนชั้นมัธยมศึกษาปีที่ 6 มุ่งเน้นการเสริมสร้างทักษะความฉลาดทางการเงิน (Financial Literacy) ควบคู่ไปกับทักษะการเขียนโปรแกรม ผู้เรียนจะได้เรียนรู้การดึงข้อมูลสถิติย้อนหลัง การเชื่อมต่อ API ของระบบสารสนเทศการลงทุน และการทำ Backtest เพื่อประเมินความเสี่ยงและพัฒนาระบบอัลกอริทึมเทรดดิ้ง (Algorithmic Trading) ด้วยตนเอง

โครงสร้างเนื้อหา (Course Syllabus)

Unit 1: Financial Literacy & Market Data
8 ชั่วโมง
ทำความเข้าใจกลไกตลาดการเงินเบื้องต้น ความเสี่ยงทางการเงิน วินัยการลงทุน และการวิเคราะห์ข้อมูลทางสถิติ (Statistical Data) เพื่อใช้ประกอบการตัดสินใจ
Unit 2: Python for Data Analysis
12 ชั่วโมง
ทบทวนการเขียนโปรแกรมภาษา Python และการใช้ไลบรารีสำหรับการจัดการข้อมูล (Pandas, NumPy) เพื่อวิเคราะห์แนวโน้มและสร้าง Data Visualization
Unit 3: API Integration & System Architecture
10 ชั่วโมง
การตั้งค่า API Integrations เพื่อดึงข้อมูลราคาแบบ Real-time เข้าสู่ระบบ และทำความเข้าใจโครงสร้างคำสั่งในการส่งข้อมูล
Unit 4: Trading Bot Development & Backtesting
10 ชั่วโมง
พัฒนาระบบเทรดอัตโนมัติ (Trading Bot) พร้อมการทดสอบระบบด้วยข้อมูลย้อนหลัง (Backtests) เพื่อวัดประสิทธิภาพและปรับปรุงอัลกอริทึม

ข้อมูลรายวิชา

  • ระดับชั้น มัธยมศึกษาปีที่ 6
  • เวลาเรียน 40 ชั่วโมง / ภาคเรียน
  • ประเภทวิชา วิชาเพิ่มเติม
  • การประเมินผล Project-based
